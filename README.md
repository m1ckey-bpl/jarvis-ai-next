## What is JARVIS?

JARVIS is a premium, native iOS AI personal assistant. It is not a chatbot wrapper. It is not a web app. It is a genuinely functional, maintainable Swift/SwiftUI application designed to feel like talking to an intelligent digital person who understands your requests and performs authorized tasks for you.

**Key capabilities:**
- 🗣️ **Real-time voice** — Speak naturally; JARVIS listens, thinks, and speaks back
- 🤖 **Animated face** — Human-like avatar with speech-driven lip synchronization
- 🧠 **Persistent memory** — Remembers facts, preferences, and decisions across sessions
- ⚡ **Autonomous agent** — Executes real tasks (reminders, email, calendar, GitHub)
- 🔒 **Zero-cost** — Free Gemini Flash / Groq inference, free GitHub Actions, on-device voice
- 📱 **Unsigned IPA** — Download, sign with AltStore/Sideloadly, install on your iPhone

## Getting Started

### Prerequisites
- iPhone running iOS 17.0+
- A free [Gemini API key](https://aistudio.google.com/app/apikey) **or** a free [Groq API key](https://console.groq.com)
- [AltStore](https://altstore.io) or [Sideloadly](https://sideloadly.io) to install the unsigned IPA

### Install the App
1. Download `JarvisApp-X.X.X-unsigned.ipa` from [Releases](https://github.com/m1ckey-bpl/jarvis-ai-next/releases)
2. Sign and install using AltStore or Sideloadly (see [docs/GET_THE_IPA.md](docs/GET_THE_IPA.md))
3. Open JARVIS → Settings → AI Provider → paste your API key → **Save and activate**
4. Return to home and tap the mic — say "Hello, JARVIS"

### Build from Source
```bash
# Requires macOS + Xcode 15+
python3 scripts/generate_xcode_project.py
xcodebuild -project ios/JarvisApp.xcodeproj -scheme JarvisApp \
  -sdk iphoneos -configuration Release \
  CODE_SIGNING_ALLOWED=NO build
bash scripts/build_unsigned_ipa.sh
```
